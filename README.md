## 🌐 Сайт проекта

Официальный сайт калькулятора — витрина «Монолита» в эстетике
индустриального брутализма.

**Что на сайте:**

- **Герой-блок** с девизом *«Точно. Надёжно. По-нашему»* и кнопкой
  перехода в калькулятор.
- **Легенда триколора** — объясняет логику клавиш: белое вводит,
  синее считает, красное управляет.
- **Четыре режима работы** — Обычный, Инженерный, Финансы РФ, Стройка.
- **Блок доверия** — офлайн-работа, никаких зависимостей, открытый код.
- **Блок «В разработке»** — честно про платформы.
